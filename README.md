# Rock Paper Scissors Game ✊✋✌️

A classic Rock Paper Scissors game playable in the browser. First player to reach 5 points wins!
Features

Play against the computer by clicking buttons
Real-time score tracking
Winner announcement when a player reaches 5 points
Game reset button to start a new game
Responsive and clean UI

How to Play

Click on Rock, Paper, or Scissors to make your choice
The computer randomly picks its choice
The result and updated score are displayed after each round
First to 5 points wins the game
Click Reset to start a new game at any time

Game Rules

Rock beats Scissors
Scissors beats Paper
Paper beats Rock
Same choice = Tie

Technologies Used

HTML5
CSS3 (with CSS variables and nested selectors)
Vanilla JavaScript (DOM manipulation, event listeners)
